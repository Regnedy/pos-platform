# POS Platform - Plataforma POS Inteligente

## 📱 Proyectos

### Android POS
- Ubicación: `/android`
- Tecnología: Kotlin + Jetpack Compose
- Propósito: Punto de venta móvil, offline-first

### Laravel Web Backend
- Ubicación: `/laravel-web`
- Tecnología: Laravel 10 + Vue 3
- Propósito: Backend, dashboard, sincronización
